## 2. FDA 510(k) 路径

### 2.1 产品分类

根据 FDA 产品分类规则：

```
产品代码: 90 IYO (Medical Image Display)
设备类别: Class II
审查途径: 510(k) Premarket Notification
```

### 2.2 预期用途声明

> "AI Adaptive Medical Display System 是一款医用显示器辅助设备，用于在医疗机构中显示医学影像。该设备通过AI技术自动识别影像模态并调整显示参数，辅助医疗专业人员查看和诊断医学影像。本设备不用于独立诊断，也不替代专业医疗人员的判断。"

| 对比项目 | 申报设备 | 参照设备 (KXXXXXXXX) |
