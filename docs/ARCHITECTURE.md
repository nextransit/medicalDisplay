## 关键设计决策

### 1. 跨平台设计

- 使用 C API 提供跨语言绑定能力
- 平台特定实现通过条件编译隔离
- 统一的接口抽象隐藏平台差异

### 2. 性能优化

- Zero-copy 纹理共享 (DMA-BUF)
- GPU 异步计算
- NPU 专用推理优化

### 3. 医疗合规

- DICOM Part 14 GSDF 完整实现
- 原始数据完整性保留
- AI 增强参数可追溯
