## 6. 竞争策略

### 6.1 竞争优势

1. **先发优势**: AI+医疗显示细分市场首个产品
2. **技术领先**: 边缘AI + 联邦学习
3. **本地化**: 深度适配中国医疗环境
4. **合规**: 提前布局FDA/CE认证

### 6.2 定价策略

| 场景 | 策略 |
|------|------|
| 标杆医院 | 适中价格 + 长期服务 |
| 政府采购 | 性价比优先 |
| 医疗集团 | 套餐折扣 + 战略合作 |
| OEM合作 | 利润分成模式 |
