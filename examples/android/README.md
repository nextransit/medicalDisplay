# Android 示例项目

该目录提供一个可扩展的 Android 示例工程骨架，用于演示：

- 原生层初始化医疗显示能力
- 生成模拟影像任务
- 展示 DICOM 接收 / 多屏同步 / OTA 状态

## 目录

```text
examples/android/
├── settings.gradle.kts
├── build.gradle.kts
├── gradle.properties
└── app/
    ├── build.gradle.kts
    └── src/main/
        ├── AndroidManifest.xml
        ├── cpp/
        ├── java/com/medicaldisplay/examples/
        └── res/
```
